# Handbuch für Betreiber

Dieses Handbuch erklärt die Funktionen der Website aus Sicht des Vereins: **was** sie können,
**wo** man sie einstellt und **was** man dafür außerhalb der Website einrichten muss (Discord,
Dolibarr, Google Play …). Jedes Kapitel ist zum Durchlesen gedacht – ohne Programmierkenntnisse.

Technische Hintergründe für die Entwicklung stehen in den Dateien unter [`docs/`](../) und in der
[Dokumentationsübersicht](../../DOCS.md).

Die Kapitel nach dem Muster des Discord-Kapitels (Überblick → Einrichten → jede Funktion →
Fehlerbilder → Häufige Fragen) folgen nach und nach; bis dahin verlinkt die Tabelle die
vorhandenen Anleitungen.

## So ist jedes Kapitel aufgebaut

1. **Überblick** – was die Funktion für den Verein tut, in einer Tabelle.
2. **Einrichten** – einmalig, Schritt für Schritt, mit Klickwegen.
3. **Die Funktionen einzeln** – was passiert, wo man es einstellt, was es braucht.
4. **Wenn etwas nicht klappt** – Fehlerbild → Ursache → Lösung.
5. **Häufige Fragen.**

Klickwege stehen so: **Admin → Verbindungen → Discord → Reiter „Server“**. Was im Admin
„Verbindungen“ heißt, ist die Adresse `/admin/integrations`.
